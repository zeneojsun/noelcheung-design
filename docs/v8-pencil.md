# V8 Pencil

## V8 direction

Clean, calm, editorial, senior, system-oriented.
The site should feel like an independent senior product designer with strong systems thinking and visual craft.

## What we keep

* Light warm background
* Narrow content column
* Serif intro
* Simple navigation
* Clear selected work list
* Calm spacing
* Minimal motion
* Strong writing-like rhythm

## What we avoid

* Sales-page layout
* Overly dark crypto aesthetic
* Heavy gradients
* Glow effects
* Large stats band
* Too many CTAs
* Over-explaining on homepage
* Rebuilding layout repeatedly

## Homepage structure

1. Header
2. Intro / hero
3. Current focus
4. Selected work
5. Writing / notes
6. About
7. Contact
8. Footer
